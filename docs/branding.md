# Doctopus brand

**Give your API a helping hand.**

Doctopus brings beautiful API references, readable guides and interactive exploration together in a documentation platform you can host yourself. The identity connects a curious octopus with the many frameworks, specifications and workflows the product supports.

## Name and voice

Write **Doctopus** in prose and headings, and `doctopus` in command names, URLs and technical identifiers. Use **Doctopus UI**, **Doctopus Studio**, **Doctopus CLI** and **Doctopus for Spring Boot** when naming components. Avoid unrelated abbreviations or alternate capitalization.

The voice is clear, capable and lightly playful. Use the helping-hand idea for introductions and milestones; keep errors, permissions, security decisions and API reference text direct. The mascot supports the content instead of becoming a distraction.

## Logo kit

![Doctopus logo](../assets/brand/doctopus-mascot.webp)

The primary logo is a violet cartoon octopus with expressive eyes, suction-cup details and an open code book. A compact monochrome octopus companion supports small interface placements. The curled arms suggest code brackets and integrations. Use the complete silhouette, preserve its proportions and leave at least one eye diameter of clear space around it. Pair it with the written name where recognition matters. Small interface marks are decorative when adjacent text already names the product.

Available in [the brand asset directory](../assets/brand/):

- `doctopus-mascot.webp`: detailed, transparent primary mascot, optimized for the interface.
- `doctopus-app-icon.png`: 512 × 512 mascot export.
- `doctopus-mark.svg`: compact violet companion mark.
- `doctopus-mark-dark.svg`: lavender compact mark for dark surfaces.
- `doctopus-mark-ink.svg` and `doctopus-mark-white.svg`: monochrome variants.
- `doctopus-wordmark.svg`: adaptive light/dark horizontal lockup for the README.
- `doctopus-wordmark-light.svg` and `doctopus-wordmark-dark.svg`: horizontal lockups, with corresponding PNG exports.
- `doctopus-social.svg` and `doctopus-social.png`: 1280 × 640 repository and sharing artwork.
- `doctopus-logo-source.png`: original generated artwork with transparency.

The mascot artwork was created with an image-generation tool for this project. The compact SVG companion was traced from the simpler initial logo concept. Production mascot assets are local WebP files; there are no external image or font services. Brand assets use the repository's Apache-2.0 license.

## Color and typography

| Role           | Light appearance      | Dark appearance    |
| -------------- | --------------------- | ------------------ |
| Identity       | Violet `#7c3aed`      | Lavender `#c4b5fd` |
| Primary action | Deep violet `#6d28d9` | Lavender `#c4b5fd` |
| Brand ink      | `#241b3b`             | `#f7f4ff`          |
| Brand canvas   | `#f7f4ff`             | `#191326`          |

Deep violet on white has 7.10:1 contrast; lavender on the dark brand canvas has 9.79:1 contrast. Both exceed the 4.5:1 target for normal text. The Studio retains its existing neutral content surfaces and semantic status colors.

Reserve identity colors for the mark, active navigation and primary actions. Keep operation methods, warnings and errors semantically distinct. Use the existing system-font stack, a confident semibold/bold wordmark and monospace for code. No external font download is required. The SVG wordmarks retain real text, so their typography uses the viewer's installed system fonts.

Use the existing responsive island layout, accessible focus indicators, reduced-motion behavior and prepared reader themes. Customer logos and configured themes remain configurable; Doctopus branding must not overwrite them.
