## Your API deserves a great first impression

Doctopus turns API specifications into beautiful, self-hosted documentation. Orbit, our fictional API for projects and webhooks, supplies the sample data. This demonstration is a complete static documentation site, built from Markdown and an OpenAPI specification and hosted on GitHub Pages.

> **Try everything with mock data.** Open any endpoint, choose **Try now**, then **Send mock**. Responses are generated in your browser from bundled examples. No API server, account, credentials or database is involved. Edits do not persist or create real resources.

## Make yourself at home

- **Explore the reference.** Inspect parameters, request bodies, nested schemas and documented responses.
- **Try the playground.** Change request inputs, copy a URL or snippet, generate a response and expand it fullscreen. The response editor supports syntax highlighting, folding and copying.
- **Choose your workspace.** Open reader settings for prepared themes, system/light/dark appearance, and a classic collapsed endpoint list. Response colors follow your theme automatically.
- **Find your way.** Search the site, filter All / Documentation / API Reference, and resize the modern navigation and inspector panels.

## Built for your stack

Add the bundled API reference to Spring Boot, Express or Fastify with an OpenAPI URL and runtime settings. No documentation project file or site build is needed. For authored guides and advanced publishing, Doctopus also builds static sites from YAML or JSON API specifications. Neither setup needs a database; the optional management server adds access control and publication workflows.

Start with the [playground tour](quickstart.md), explore [workspace customization](workspace.md), or browse the API Reference tab.
