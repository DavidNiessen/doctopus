## Pick a theme

Open reader settings in the header and choose Mint, Ocean, Violet or Neutral, or restore the published theme. Appearance can follow your system or stay light or dark. The response editor automatically uses matching colors.

Your preferences stay in this browser for this documentation site. They synchronize across open tabs without changing the published project.

## Choose a layout

**Modern documentation** keeps navigation, documentation and examples in adjustable columns. Drag the gutters to resize them, or focus a divider and use the arrow keys. Home and End select its minimum and maximum widths.

**Classic API reference** shows collapsed, method-colored endpoints in the main page. Expand a row for details, then open the same mock playground. Guides retain their navigation.

## Publish your branding

Project authors configure logos, typography, density, colors and sizing in YAML or JSON. The build validates tokens and text contrast. Plugins extend source loading, code examples and other documented integration points.

Visit the [source and operator documentation](https://github.com/DavidNiessen/doctopus) to build and host your own site.
